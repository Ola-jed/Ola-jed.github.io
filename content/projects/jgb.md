## Overview

**jgb** is a high-performance symbolic algebra library for Java, engineered for the exact computation of Gröbner bases in polynomial rings.

Built with **Java 21**, it provides a pure-Java implementation of state-of-the-art algebraic algorithms, offering a robust foundation for researchers and developers working in cryptography, robotics, and computational geometry.

### Key Features

* **Multi-Algorithm** — Supports Buchberger, F4, Improved F4, and the modern M4GB algorithm.
* **Rich Algebraic Fields** — Support for Rationals, Reals, Complex numbers, and Galois Fields.
* **Flexible orderings** — Comprehensive monomial orderings including Lex, Grlex, Grevlex, and Weighted.
* **Benchmark tools** — Built-in generators for standard polynomial systems like Katsura and Reimer.
* **Zero dependencies** — A lightweight, standalone library with no external requirements.
